# 3–5 分钟演示脚本

这是讲解脚本。实际三分钟无旁白录制位于 `output/demo/AshenSupport-walkthrough.mp4`，使用浏览器实操和说明字幕；下列口述内容可用于后续配音。浏览器 screenshot/trace 不等同于有讲解的视频。

## 0:00–0:35 产品与边界

展示工作台，说明服务两个自己维护的开源项目；当前 fake provider 是确定性演示，模拟诊断始终标注。解释真实在线配置单独验收。

## 0:35–1:30 RAG 排障

点 RAG 场景 → 开始排查 → 看实际检索/工具步骤 → 展开文档引用，展示版本、行号、片段。说明答案与来源不是随意拼接，服务端验证引用 ID。

## 1:30–2:20 审批与工单

生成草稿 → 编辑标题并保存 → 批准 → 工单列表。指出需要确认当前版本；并发审批测试确保重复请求只有一个工单。刷新任务页展示持久记录。

## 2:20–3:00 证据不足

新建未知问题场景 → 展示补问和信息不足状态。说明补问次数有限，系统不会无限循环或捏造根因。

## 3:00–3:40 工程能力

展示架构、PostgreSQL 任务领取和 fencing 测试；说明进程中断恢复与模型重复费用窗口。切管理员知识库，看版本索引状态。

## 3:40–4:30 评估与限制

打开实际评估报告：说明 fake 契约测试和真实 AI 效果的区别。80 条草稿需人工校对，未测指标为未知。讲解一个失败案例和下一步实验。
